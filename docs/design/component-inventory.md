# NoorPath Component Inventory V1.0

Status: Foundation baseline

## Foundations

- Brand and semantic colour tokens
- Type scale and readable content widths
- Spacing, radius, elevation, icon, and motion tokens
- Responsive breakpoints
- Focus, disabled, loading, error, success, and reduced-motion states

## Pilot primitives

- Button, icon button, link
- Text field, select, checkbox, radio group, date input
- Alert, status badge, tooltip, dialog, bottom sheet
- Card, section, divider, skeleton, empty state
- Header, footer, breadcrumb, step indicator

## Trust and commerce components

- Verified operator identity
- Total-price and due-now disclosure
- Instalment timeline
- Included/optional/excluded matrix
- Confirmed/pending service status
- Cancellation and refund summary
- Human-support panel
- Secure-document explanation

## Package components

- Package tier badge: Economy, Standard, Premium, Custom
- Package discovery card
- Tier comparison
- Hotel option with verified imagery and source
- Room configuration
- Day-by-day itinerary
- Transport and meal details
- Travel-kit and Umrah-kit contents
- Seat/inventory status without artificial urgency

## Approval rule

A component enters the baseline only after responsive, keyboard, screen-reader, reduced-motion, loading, error, and screenshot states are reviewed. Operator-configurable content must be tested with missing, long, multiple, and conditional values.
