# ADR-0002: Shared Tokens, Platform-Appropriate Components

- Status: Accepted
- Date: 2026-07-28

## Decision

Share brand tokens, motion rules, icons, contracts, validation rules, translation keys, and analytics names across platforms. Build platform-appropriate web and future mobile components rather than forcing full UI code sharing.

The web pilot uses the approved modern-minimalist NoorPath direction: Haram ivory, Kaaba black, Kiswah gold, Madinah green, and Saudi sandstone. Religious imagery must be respectful, licensed, authentic, and never used as an unsupported trust signal.

## Consequences

- Web and mobile remain visually consistent.
- Each platform retains appropriate interaction and accessibility behavior.
- Visual baseline changes require review and versioning.
